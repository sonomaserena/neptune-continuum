# University of Greater Neptune — Campus Bible Index

*Shared-world setting bibles; November 2026*

The systemwide institutional history lives in `canon/Greater Neptune Region - The University of Greater Neptune.md`. The regional **Master Reference v3** governs shared facts. These files expand campus-scale architecture, operations, student life, memory, and story routes. Every new detail is public-register worldbuilding.
